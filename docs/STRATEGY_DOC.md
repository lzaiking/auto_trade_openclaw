# Trading Strategy Document

## 项目目标

当前目标是把系统拆成可独立评估的三个模块，并逐步优化到：

- 年化收益目标：`30%`
- 最大回撤：不高于当前每月定投 QQQ 基线

基线保持不变：

- 每月第一个交易日投入 `10,000`
- 全部买入 `QQQ`

策略同样每月投入 `10,000`，但策略模块只读取预测模块给出的 `QQQ / GLD / SGOV` 当前分数和未来 30 个自然日窗口预期收益，再决定当月目标仓位。

## Module 1：预测模块

预测模块只做一件事：用当月可见因子预测未来 30 个自然日窗口收益，并评估预测准确度。

输出形式：

- `predicted_1m_return`
- `actual_forward_1m_return`
- `actual_forward_1m_avg_return`
- `prediction_error`
- `model_coefficients`
- `sample_size`

当前预测模块同时输出一个 `0 ~ 1` 上涨分数。`0.5` 代表中性，越高代表未来 30 个自然日窗口上涨概率和预期收益越好，越低代表下跌风险越高。当前候选分数包括方向概率、收益幅度分数和两者混合分数；每个月只用历史 OOS 表现选择当前资产采用哪个分数组件。

当前资产：

- `QQQ`
- `GLD`
- `SGOV`

因子入口：

- `data/factors/monthly_factors.csv`

当前模板字段：

- `eps_revision_score`
- `forward_peg_score`
- `fcf_yield_minus_tbill`
- `ai_profit_conversion_score`
- `top_weight_concentration`
- `breadth_200dma`
- `crowding_score`

因子数据校验：

- 自动检查字段是否完整
- 自动检查日期格式和重复月份
- 自动检查数值是否落在合理范围
- 自动统计每个因子的覆盖率
- 自动输出 `report/factor_validation.json`

代码会自动为每个资产补充价格类因子：

- 资产偏离 200 日均线
- 14 日 RSI
- 63 日涨幅

后验 label 有两个口径：

- 端点价：当前日期往后 30 个自然日，若当天休市则取之后第一个可用交易日，计算 `price[label_end] / price[t] - 1`
- 均价：从当前日之后到 `label_end` 之间所有交易日价格均值，计算 `average(price[t+1]...price[label_end]) / price[t] - 1`

预测准确度评估：

- 整体 AUC：未来 30 个自然日对应交易日价格是否高于当前价
- 整体均价 AUC：未来 30 个自然日窗口内交易日平均价格是否高于当前价
- 每个资产 AUC 和每个资产均价 AUC
- 每年 AUC 和每年均价 AUC
- 每个特征的数据覆盖率
- 单特征 AUC
- 分数分桶校准：高分桶是否真的优于低分桶
- MAE / MSE
- 方向准确率

防穿越规则：

- 每个月只用该月以前的数据训练模型
- 训练样本的 30 自然日窗口后验 label 必须已经完整结束，才允许进入训练集
- 当月后验 label 只用于之后月份训练和事后评估
- 策略模块不能读取未来收益

## Module 2：策略模块

策略模块不训练模型、不调预测系数，只读取预测模块输出的：

- `score_QQQ / score_GLD / score_SGOV`
- `pred_QQQ / pred_GLD / pred_SGOV`

正式策略规则：

- 用每个资产的 `score - 0.5` 和正向 `predicted_1m_return` 计算吸引力
- 默认至少保留 `85%` QQQ 核心仓位
- GLD 权重上限为 `15%`
- SGOV 权重上限为 `20%`
- 如果 QQQ 分数低于 `0.45` 且预测收益低于 `-1%`，允许额外转入 SGOV

防守仓位规则：

- 如果 `GLD` 偏高，则 GLD 吸引力按 `0` 处理
- `GLD` 偏高定义为：偏离 200 日均线达到 `10%` 以上，或 14 日 RSI 达到 `70` 以上
- 固定阈值策略仍作为 `fixed_threshold_scenario` 保留，用来对照

这样做的原因：

- 当前真实基本面因子还没填入
- 价格因子训练出的 AUC 不够强
- 策略要使用多资产分数和预期收益，但仓位上限必须保守，避免弱预测被放大

策略模块同时输出两个压力/上限场景：

- `oracle_scenario`：假设预测完全准确，每月买未来 30 个自然日窗口实际最好的资产
- `worst_case_scenario`：假设预测完全错误，每月买未来 30 个自然日窗口实际最差的资产

这两个场景用来判断：

- 预测如果足够准，策略理论上能达到多高收益
- 预测如果完全错，组合会承受多大损失和回撤
- 后续止损线和仓位上限应该设在哪里

当前回测模块根据基线回撤和 worst-case 场景给出三条风控线：

- 预警线：组合回撤达到 `15.22%`
- 降风险线：组合回撤达到 `18.27%`
- 止损线：组合回撤达到 `20.30%`

执行规则：

- 到达预警线后，非 QQQ 倾斜仓位上限降到 `5%`
- 到达降风险线后，至少保留 `30% SGOV`
- 到达止损线后，暂停新增 QQQ/GLD 倾斜，新增月供先进 `SGOV`，等下次月度评估

## Module 3：回测模块

回测模块输出：

- `report/backtest_summary.json`
- `report/equity_curve.csv`
- `report/factor_validation.json`
- `report/factor_predictions.csv`
- `report/prediction_calibration.csv`
- `report/prediction_metrics.json`
- `report/leakage_audit.json`
- `report/module_scorecard.json`
- `report/scenario_analysis.csv`
- `report/strategy_sweep.csv`
- `report/latest_orders.json`

核心评估：

- 策略 vs 月定投 QQQ
- 是否达到 `30%` 年化目标
- 最大回撤是否不高于基线
- 预测模块整体 AUC 和年度 AUC
- 预测分数分桶校准
- oracle 上限收益
- worst-case 最大损失和最大回撤
- score+return 策略、固定阈值策略、QQQ 定投之间的收益和回撤

## 当前结果

截至 `2026-06-05`：

| 对象 | 年化 IRR | 最大回撤 | 结束权益 |
| --- | ---: | ---: | ---: |
| Legacy 信号策略 | `22.03%` | `20.28%` | `1,048,631.72` |
| 模型 score+return 对照 | `19.58%` | `19.03%` | `988,510.98` |
| 固定阈值对照 | `19.48%` | `18.08%` | `986,209.03` |
| 月定投 QQQ | `22.66%` | `20.30%` | `1,064,681.31` |
| Oracle 上限 | `79.34%` | `13.54%` | `3,723,537.50` |
| Worst-case | `-23.61%` | `18.48%` | `335,222.03` |

策略诊断：

- QQQ 最新规则预估 30 个自然日窗口收益：`0.80%`
- 最新目标仓位：`90.00% QQQ / 10.00% GLD`
- 模型 score+return 对照：`19.58%` 年化、`19.03%` 最大回撤
- 固定阈值对照：`19.48%` 年化、`18.08%` 最大回撤
- 策略年化 IRR 低于 QQQ 定投，但最大回撤更低
- 当前距离 30% 年化目标还差约 `7.97%`

这说明 legacy 信号策略比模型 score+return 对照更接近 QQQ 定投，但仍无法稳定跑赢 QQQ 定投；下一步不应该继续硬调模型仓位，而应该补齐真实因子并继续验证 QQQ 规则信号。

预测模块当前表现：

- 规则预估整体端点价 AUC：`0.4808`
- 规则预估 30 自然日窗口均价 AUC：`0.4326`
- 规则预估 `QQQ` 端点价 AUC / 均价 AUC：`0.5486` / `0.4774`
- 模型对照整体端点价 AUC / 均价 AUC：`0.5281` / `0.5848`
- 模型对照 `QQQ` 端点价 AUC / 均价 AUC：`0.4785` / `0.4689`
- 防穿越审计：通过，`0` 个违规训练样本

分数校准当前表现：

| 资产 | 端点高低收益差 | 均价高低收益差 | 端点高低上涨率差 | 均价高低上涨率差 |
| --- | ---: | ---: | ---: | ---: |
| QQQ | `-1.82%` | `-0.48%` | `0.00%` | `0.00%` |
| GLD | `0.40%` | `0.70%` | `-8.33%` | `-8.33%` |
| SGOV | `0.01%` | `0.15%` | `16.67%` | `25.00%` |

这说明当前分数在 `SGOV` 上排序能力较强，`GLD` 的端点收益校准较好，但 `QQQ` 的端点收益高分桶仍没有优于低分桶；均价口径比端点口径更能反映“未来一段时间是否整体更高”。策略不能放大仓位，原因不只是 AUC 未达标，也包括分数校准仍不稳定。

当前特征覆盖率：

- EPS 修正：`0%`
- forward PEG：`0%`
- FCF yield 相对短债：`0%`
- AI capex 利润兑现：`0%`
- 指数集中度：`0%`
- 市场宽度：`0%`
- 拥挤度：`0%`
- 价格类因子：`100%`

因子验证当前状态：

- `monthly_factors.csv` 结构通过
- 行数：`0`
- 基本面因子覆盖率：`0%`
- 报告提示：当前文件只有表头，尚不能用 EPS/PEG/FCF 等因子证明预测能力

当前单特征 AUC：

- 资产偏离 200 日均线：`0.5127`
- 14 日 RSI：`0.5902`，方向为 lower-is-better
- 63 日涨幅：`0.5315`

结论：

- 当前策略略低于基线收益，但回撤略低于基线
- 距离 `30%` 年化目标还有明显差距
- 当前距离 30% 年化目标还差约 `10.42%`
- oracle 场景说明资产轮动有足够上限，但当前预测模块 AUC 不够
- 当前报告已经证明 EPS、PEG、FCF yield、AI capex、breadth、crowding 还没有历史数据覆盖
- 下一步应该优先补齐这些真实月度因子，而不是继续硬调策略仓位

## 下一步优化顺序

1. 补齐 `monthly_factors.csv` 的历史因子
2. 先看预测模块 AUC 是否能稳定高于 `0.6`
3. 如果预测有效，再评估是否提高 score+return 策略的 GLD/SGOV 权重上限
4. 用 worst-case 场景倒推最大单月防守/进攻仓位和止损线
5. 再评估是否能接近 `30%` 年化目标

## 一句话概括

当前版本已经把预测、策略、回测拆开：预测模块预测未来 30 个自然日窗口收益和 0-1 分数，并同时评估端点价与窗口均价两个 AUC 口径；策略模块按 `QQQ / GLD / SGOV` 的分数和收益期望做保守配置，回测模块负责检查防穿越、AUC、基线对比、oracle 上限和 worst-case 风险。
